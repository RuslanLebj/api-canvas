# API Canvas

Локальный dashboard для сборки и выполнения HTTP-запросов из Swagger/OpenAPI.

## Несколько API на одном холсте

Подключите первый Swagger, затем нажмите «+ API» и введите адрес следующего.
Переключатель «Сервис» выбирает библиотеку роутов и Base URL для выбранного API.
Добавленные карточки остаются на общем холсте и выполняют запросы к своему сервису,
даже когда в библиотеке выбран другой API. Под названием карточки показан её сервис
и адрес. Шаблоны одинаковых роутов в разных сервисах независимы.

Карточки разных API можно соединять существующими связями полей и объединять
в сценарии. Все сервисы сохраняются вместе с холстом в браузере и в JSON-экспорте.
Ранее сохранённые холсты с одним API подхватываются автоматически.

## Запуск для разработки

```powershell
npm install
npm run dev
```

Откройте `http://127.0.0.1:5173`. Backend-proxy слушает только
`http://127.0.0.1:4174`.

## Production-сборка и локальный запуск

```powershell
npm run app
```

После сборки приложение доступно по `http://127.0.0.1:4174`.

## Запуск в Docker

```powershell
docker compose up --build -d
```

Контейнер публикует dashboard на всех сетевых интерфейсах хоста (`0.0.0.0:4174`).
С другого устройства в той же локальной сети откройте `http://<LAN-IP>:4174`.
У proxy нет собственной авторизации, поэтому не пробрасывайте этот порт в интернет.
Адреса Swagger и API
вида `http://localhost:8000` внутри proxy автоматически направляются на хост через
`host.docker.internal`; отображаемый URL и генерируемый curl при этом не меняются.

## Проверки

```powershell
npm run check
```

Приложение предназначено для локальной работы. Proxy принимает произвольные URL
и headers, поэтому его нельзя публиковать в сеть без дополнительной авторизации и
ограничения целевых адресов.
